# Kayser Ahmed Portfolio Website


## Files

- `index.html` - portfolio content and structure
- `styles.css` - visual system, layout, and responsive styling
- `script.js` - scroll reveal, active navigation, magnetic buttons, card tilt, and animated neural canvas
- `assets/` - generated medical-imaging visuals and downloadable CV

## Design References

The direction blends ideas common to high-end portfolio and product sites:

- Apple-style hero confidence and typography restraint
- Stripe-like technical credibility and motion polish
- Linear-style dense, refined product UI spacing
- Awwwards-style immersive first viewport
- Academic-lab clarity for publications, methods, and evidence

## Run

Open `index.html` directly in a browser, or serve the folder locally:

```bash
python3 -m http.server 8080
```
